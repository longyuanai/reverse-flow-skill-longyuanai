# 商业授权采购常见问答 (Commercial Purchase FAQ)

### Q1: 哪些场景必须采购商业授权？
根据 [PolyForm Noncommercial License 1.0.0](../../LICENSE) 规定，凡是将本项目用于**营利性商业目的**的均需购买商业授权，包括但不限于：
1. **企业内部使用**：企事业单位 SOC 团队、安全研究团队在日常企业业务或生产环境中使用。
2. **商业项目交付**：独立顾问、安服厂商在向第三方客户提供收费的渗透测试、代码审计或逆向分析服务中使用。
3. **商业产品集成**：将本项目的 CIL 解析引擎、差分核验模块或分诊脚本嵌入商业软件、硬件设备或 SaaS 平台中。
4. **商业培训收费**：开展收费的逆向安全培训并分发本套件作为实战课件。

*注：高校师生教学、非营利性学术科研、学生个人学习及非营利 CTF 竞赛打靶完全免费，无需购买。*

### Q2: 能否开具增值税专用发票？发票类目是什么？
**完全支持**。
- **开票主体**：提供正规合规税务开票。
- **发票类目**：通常开具为 `*信息技术服务*软件授权费` 或 `*信息技术服务*技术服务费`。
- **发票类型**：支持增值税电子普通发票（个人/企业均可）及增值税专用发票（面向企业财务抵扣）。

### Q3: 采购合同签署流程是怎样的？
1. 您通过邮件或 GitHub 提交公司开票信息与采购版本。
2. 我们在 1 个工作日内拟定 [标准商业授权协议](LICENSE-AGREEMENT-TEMPLATE.md) 盖章扫描件发给您。
3. 贵司签字盖章并回传，通过对公转账或扫码付款。
4. 我们确认到账后，即刻提供《商业授权证书 (PDF)》并邮寄/发送增值税发票，开启技术支持服务。

### Q4: 企业内部使用私有内网 LLM (如 DeepSeek / Qwen)，该技能如何支持？
企业团队版及以上版本原生支持企业私有化部署：
- 技能内核使用系统标准 Python 3 实现，无第三方外部二进制强制依赖。
- 提示词与工作流针对 OpenAI API 规范、Anthropic API 规范以及支持 Tool Use 的开源大模型（如 DeepSeek-R1/V3、Qwen-2.5-Coder）均做了鲁棒性适配。
- 企业客户可获得私有模型 Prompt 与 Agent 角色配置指导。

### Q5: 授权到期后已交付的项目或代码会受影响吗？
不会。
- 在授权有效期内合法交付的商业报告、安全审计结论和已构建的系统集成成果，其合法性永久受保护，无需因为授权到期而推倒重做。
- 到期后若不续费，仅停止接收最新特征库升级和专属技术支持服务，企业内不得新增席位或开启新的商业外包项目。
