导语：过去一年里，大语言模型在写代码、审源码上如鱼得水。但在二进制逆向与 CTF 题面前，却经常被“看似自信、实则全错”的逆向幻觉所支配。今天，我们正式开源「真心为你 & 破甲」双技能套件，用确定性代码与差分核验彻底驯服 AI 逆向！

一、大模型逆向的三大“灾难级”幻觉

  • 幻觉灾难 1：面对反汇编指令，模型看似胸有成竹，分析起算法来头头是道，结果写出来的 Python 还原代码一跑——全是错的；
  • 幻觉灾难 2：在干净沙箱或轻量容器里，没有安装商业级 IDA Pro、Ghidra 或 ILSpy 时，模型立刻两手一摊：“环境缺少工具，无法分析”；
  • 幻觉灾难 3：分析过程全凭黑盒推理，没有任何证据快照和验证闭环，结论无法被独立重跑与核验。

二、核心突破：AI 负责假设，确定性代码负责核验

整个项目由两个深度协同的技能组成：

1. reverse-flow（全局分诊与流程控制）

口令【真心为你】启动，负责样本隔离、SHA256 哈希固化、多维静态分诊（PE/ELF/信息熵/高危指标清洗）以及输出工业级审计报告。

2. pojia 破甲（深度逆向与算法还原）

口令【破甲】启动，针对加壳、复杂算法、混淆控制流执行外科手术式解剖与数学级差分核验。

✦ 突破 1：零外部依赖自举 CIL 反编译引擎 (inspect_cil.py)

在没有安装任何反编译器（dnSpy/ILSpy）的极端精简沙箱中，我们利用 Python 纯标准库手工完整实现 ECMA-335 CLI 标准 解析：

# 纯 Python 零依赖提取 .NET 字节码与 Token
python skills/pojia/scripts/inspect_cil.py sample.exe --method Transform --format text

✦ 突破 2：零依赖 Native 原生入口点与 x86/x64 解码 (inspect_native.py)

针对 PE32/PE32+ 及 ELF32/ELF64 原生编译二进制，利用纯 Python 结构体映射虚拟地址到物理文件偏移，并内置指令流解码器：

# 纯 Python 解析 Native 入口点指令流 (prologue, calls, syscall)
python skills/pojia/scripts/inspect_native.py sample.exe --json

✦ 突破 3：黑盒差分核验器，100% 杜绝 AI 幻觉 (diff_verifier.py)

大模型还原出来的 Python 代码到底对不对？别猜！自动向原程序与 Python 代码并发注入海量边界测试用例（0, 1, 2^n, 0xFFFFFFFF, 随机语料），逐个比对二进制与 Python 输出，必须 100% 匹配 才能交付！

✦ 突破 4：Craft Anything 双轨净室复刻融合 (Clean-Room Recreation)

与智能复刻框架协同，底层算法由 Pojia 负责数学一致性差分，前端界面与交互由 320 规则/视觉引擎保障保真度，实现无版权污染的 1:1 净室重构。
