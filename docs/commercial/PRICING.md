## 采购与交付流程

```text
[发起采购咨询] ──> [确认授权版本与主体] ──> [签署商业采购合同] ──> [对公转账/付款] ──> [交付商业证书与发票]
```

1. **发起咨询**：
   - 方式一：发送采购意向邮件至 `1507205727@qq.com`（标题格式：`【商业授权采购】公司/机构名称 - 意向版本`）。
   - 方式二：在 GitHub 提交 [商业授权咨询 Issue](https://github.com/longyuanai/reverse-flow-skill-longyuanai/issues/new?template=commercial_inquiry.yml)。
2. **签署合同**：
   - 我们将在 **1 个工作日内** 依据 [标准商业授权协议模板](LICENSE-AGREEMENT-TEMPLATE.md) 为您生成正式商业采购合同盖章件。
3. **付款结算**：
   - 支持对公银行转账（提供企业对公账户）。
   - 支持微信/支付宝对公商户扫码支付。
4. **交付物提供**：
   - 电子版《软件商业授权许可证书》（含唯一授权编号）。
   - 正式增值税发票（发票类目：`*信息技术服务*软件授权费` 或 `*信息技术服务*技术服务费`）。
   - 邀请进入企业客户专属微信技术交流群。
